# Post-publication checklist

- Add a repository description and the `home-assistant`, `hacs`, `hero-health`, and `smart-home` topics.
- Enable issues and Dependabot alerts/security updates.
- Protect `main`: require pull requests and baseline tests, HACS, Hassfest, and semantic title validation; disallow force pushes.
- Let Release Please create the first GitHub Release.
- Later consider Home Assistant Brands and HACS default-list submissions; neither is implied by this repository.
